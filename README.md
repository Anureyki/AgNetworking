# AgNetworking: AI for Controlled Environment Agriculture

This repository tracks my study and projects for the technologies needed to build an AI‑powered, self‑optimizing grow system — starting with mushrooms, but architected for any crop or grow style (soil, hydro, aquaponics, aeroponics).

## Why This Repo Exists
Most AgTech AI is fragmented — sensors here, automation there, no closed loop. This repo is my roadmap and lab notebook for learning the stack that makes a true learning AI possible.

## The Stack
| Folder | Focus | Why It Matters |
|--------|-------|----------------|
| `kubernetes/` | Orchestration (CKA/CKAD) | Scale from one sensor to hundreds |
| `DLI/` | AI / GPU fundamentals | The intelligence layer |
| `networking/` | IoT, edge, cloud connectivity | How sensors talk to the brain |

## How to Use This Repo
Each folder contains its own README with study notes, commands, project logs, and certification progress. This isn't a passive study guide — it's a living lab.

## Ultimate Goal
An AI that learns from my grow logs, correlates sensor data with outcomes, and suggests — then automates — environmental adjustments. First for mushrooms. Then for anything.
