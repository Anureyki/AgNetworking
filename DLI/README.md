# NVIDIA DLI Study (AI Fundamentals)

## Why DLI for AgTech?
Deep learning can turn sensor data into actionable insights:
- Predict contamination risk from temperature/humidity patterns
- Suggest optimal harvest windows
- Detect anomalies (e.g., CO2 spike, pump failure)
